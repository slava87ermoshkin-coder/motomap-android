# 🏍️ Мотокарта — Android MVP

Стартовый проект специализированного навигатора для дорожных мотоциклов.

## Сейчас реализовано

- Android-приложение на Kotlin + Jetpack Compose.
- Главный экран.
- Нижняя навигация.
- Профиль мотоцикла.
- Расход топлива.
- Вес водителя, пассажира и багажа.
- Экран текущей поездки.
- История поездок.
- Базовая статистика.
- Запрос разрешения GPS.
- Заготовки режимов маршрута: Быстрый / Мото / Красивый / Повороты.

## Пока не подключено

Карта и реальные маршруты — это следующий этап. Также пока заглушки: GPS-трекинг, камеры, светофоры, красивые дороги, офлайн-карты, GPX и полноценная БД поездок.

## Открытие в Android Studio

1. Установите Android Studio.
2. Нужен JDK 17.
3. Распакуйте архив.
4. В Android Studio выберите **Open** и укажите папку `MotoMap`.
5. Дождитесь Gradle Sync.
6. Подключите Android-телефон с включённой USB-отладкой или создайте эмулятор.
7. Нажмите **Run ▶**.

## Получение APK

В Android Studio: **Build → Build APK(s)**.

Обычно debug APK появится в:

`app/build/outputs/apk/debug/app-debug.apk`

## Загрузка в GitHub

### Вариант A — через сайт GitHub

1. Создайте новый репозиторий, например `motomap-android`.
2. Не создавайте в нём README и `.gitignore`, чтобы не возник конфликт.
3. Распакуйте этот архив.
4. На GitHub нажмите **Add file → Upload files**.
5. Перетащите содержимое папки `MotoMap`.
6. Нажмите **Commit changes**.

### Вариант B — через Git

Откройте терминал в папке `MotoMap`:

```bash
git init
git add .
git commit -m "Initial MotoMap Android MVP"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/motomap-android.git
git push -u origin main
```

Замените `YOUR_USERNAME` на свой логин GitHub.

## Важно

Не помещайте в репозиторий пароли, ключи подписи APK и API-ключи картографических сервисов.
